# 小柴 IP

## 角色定义

小柴是我们自媒体正文配图的固定视觉 IP。- 标准照（长相唯一标准）：`assets/character/sheet/`，总附 `01-front.png`，再按动作加附对应姿势，见该目录 README。
- 出处原图：`assets/character/xiaochai-origin.png`（作者自行生成，仅存档，不再作为主参考）。

默认每张图都要出现小柴。小柴不是吉祥物贴纸，而是正在认真参与系统运转的那只狗——淡定地把一件有点荒诞的事办完。

## 外形（每张都要稳定）

- 柴犬：浅柴橘色毛 + 白色口鼻和脸颊，竖立三角耳。
- **橙色渔夫帽**：固定标志，帽檐有一圈虚线缝线，帽顶一个小圆钮。永远戴着（除非帽子本身被拿来当道具）。
- 小黑豆眼，黑鼻头，嘴角一点点淡定的微笑。
- 毛茸茸卷尾巴。
- 上色手绘：黑色手绘线 + 平涂柴橘色和白色，帽子饱和橙。轮廓略微不规则，不要精致矢量、不要 3D。
- 默认体型小，占画面 1/6 ~ 1/4，不抢结构。

## 性格

- 淡定、松弛，什么事都"泡着也能办"。
- 认真，但做的事有点荒诞。
- 冷幽默，微笑但不卖萌、不撒娇。
- 像一个常年泡在信息洪流里却不慌的老操作员。

## 标志性状态（可选，不必每张）

- 半泡在一小片水里，只露出头和帽子，在水里干活。
- 用渔夫帽当桶 / 漏斗 / 舀子——**此时头上不再戴帽子，全图只能有一顶帽子**。
- 粉红小浮球是它的"目标物"。

## 常见职责

让小柴承担核心动作：

- 从水里捞起素材 / 漏掉的东西。
- 叼着线把信息源拉到一起。
- 用帽子舀信息、过滤信息。
- 卡在机器或管道里，只露出脑袋。
- 推着浮球走路径。
- 刨坑、守门、称重、记录、搬运。

## 禁止

- 不要画成 Q 版大头贴、表情包、闪亮大眼睛。
- 不要换帽子颜色、去掉帽子、给它穿别的衣服。
- 不要写实毛发、3D、厚涂。
- 不要让小柴只是站在角落里看。
- 不要让小柴抢走结构表达。

## 判断标准

如果去掉小柴，图的核心隐喻还能完全成立，说明小柴太装饰了；要重写提示词，让小柴成为动作主体。
