# 小柴封面角色层

不管选哪种封面风格，都要把下面这段角色锚点改写进最终提示词的"视觉主体"和"风格落地方式"里。

## 角色锚点（不可丢）

- 一只柴犬：柴橘色 + 白色口鼻和脸颊，竖立三角耳，小黑豆眼，淡定的微微笑，卷尾巴。
- 橙色渔夫帽：虚线缝线帽檐、帽顶小圆钮。全图只有一顶。
- 气质：淡定、松弛、认真做一件有点荒诞的事；不卖萌、不 Q 版。

## 跨风格规则

- 小柴要用所选风格的"材料"画出来：纸雕风就是纸雕小柴，像素风就是像素小柴，蚀刻版画就是蚀刻线小柴，积木风就是积木小柴。
- **橙色帽子永远保持橙色**，哪怕是黑白、单色、限定配色的风格——帽子就是全图唯一的橙色点，这是 IP 识别标志。若风格本身有强调色，帽子的橙色优先，风格强调色退让或减少。
- 风格里原本是"人物"的位置，由小柴替代；原本是"抽象装置/物件"的风格，小柴作为完成关键动作的角色出现，可以小比例，但必须清楚可认。
- 不得因为风格要求"无人物 / 无角色"而删掉小柴；遇到这种冲突，以本文件为准，把小柴做成该风格允许的最克制形态（例如剪影、线描、浮雕）但保留帽子橙色。

## 生成前自检

- 第一眼能否认出是小柴（柴犬脸 + 橙帽）？
- 是否只有一顶帽子？
- 画面里有没有真实品牌标志？有就换成通用符号。
- 数一下脚：只能四条腿，没有多出来的爪子、耳朵、尾巴？
- 小柴是否参与了标题的核心动作，而不是贴在角落？
