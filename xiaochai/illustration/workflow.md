
## 核心定位

为中文文章设计和生成 16:9 横版正文配图。目标是把文章里的关键判断、流程、结构、状态或隐喻，变成一张清爽、怪诞、有创意、可读但不说明书的手绘解释图。

默认视觉 IP 是"小柴"：戴橙色渔夫帽、浅柴橘色、表情淡定微笑的柴犬，常常半泡在水里，认真做一件荒诞但成立的事。小柴必须参与画面的核心动作，不能只是站在旁边当装饰。

## 先读这些参考

按需读取：

- `xiaochai-ip.md`：小柴的外形、性格、动作和禁忌。**每次都读。**
- `illustration/style-dna.md`：风格 DNA、颜色、禁忌。
- `illustration/composition-patterns.md`：结构类型和原创隐喻方法。
- `illustration/prompt-template.md`：单张生图提示词模板。
- `illustration/qa-checklist.md`：生成后检查和迭代。
- `assets/character/sheet/`：小柴标准照。生图时总附 `01-front.png`，按动作加附对应姿势。

## 工作流

### 1. 消化正文

提炼：核心观点、承担认知转折的段落、适合用图解释的内容、只适合文字的内容。优先选择"认知锚点"，不要平均配图。

### 2. 先出配图策略

用户只说"分析怎么配图"时，先给 shot list。每张写清楚：放在哪段后 / 主题 / 核心意思 / 结构类型 / 小柴在做什么 / 建议元素 / 建议中文标注词。默认 4-8 张，短文 1-3 张，长文不超过 9 张。

### 3. 单张生成

用户明确要求"生成 / 做图"时直接生成，不要停下来等确认。每张单独生成，不要拼图。

- 在 Codex 里：用内置 `image_gen`，附上角色原型图作参考。
- 在 Claude Code 里：没有内置生图时，输出完整英文提示词，并通过 `codex exec` 委派 Codex 生成，或交给用户贴到生图工具。

### 4. 检查与迭代

按 `illustration/qa-checklist.md` 检查，重点看：帽子还在不在、狗认不认得出、是不是被原型图带成了满屏蓝底、小柴是不是只是装饰。

### 5. 保存交付

保存到 workspace 的：

```text
assets/<article-slug>-illustrations/01-topic-name.png
```

不覆盖已有资产，除非用户明确要求。

## 输出口径

生成后交付：生成了几张、每张用途、保存路径、哪些最稳哪些可选。不要长篇解释风格理论。
